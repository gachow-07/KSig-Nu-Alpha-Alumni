# Chapter photos

Drop photos in this folder, then point to them from `content/site.ts`
as `"/images/your-file.jpg"`.

Suggested files and sizes (JPG, under ~1 MB each — the site resizes them for phones automatically):

| Photo | Suggested file name | Shape |
| --- | --- | --- |
| Wide group shot in front of the house | `hero-group.jpg` | Wide, at least 2400px across |
| Brotherhood | `brotherhood.jpg` | Landscape (4:3), at least 1000px across |
| Philanthropy | `philanthropy.jpg` | Landscape (4:3) |
| Intramurals | `intramurals.jpg` | Landscape (4:3) |
| New members | `new-members.jpg` | Landscape (4:3) |
| Exec headshots | `exec/grand-master.jpg`, etc. | Square, at least 200px |
| Approved crest (optional, from national) | `crest.png` | Square, transparent background |
